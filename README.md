# RecruitZero Content Dashboard

Unlisted GitHub Pages dashboard for the RecruitZero marketing-news workflow.

- `state.json` is the workflow source rendered by the dashboard.
- Topic and post approval buttons create GitHub issues labeled `approval`.
- Only approvals authored by `ransonproductionsllc-bit` are processed.
- Hermes mirrors Discord and GitHub approvals into the same state file.
- Completed posts and downstream assets remain in the permanent archive.

The page is intentionally marked `noindex, nofollow`, but GitHub Pages is publicly reachable to anyone who has the URL.
